AURORA FLIGHT — GAME FILES

1. Keep index.html, style.css and script.js in the same folder.
2. Create an assets folder.
3. Put your default character image at: assets/default-character.png
4. Create assets/audio and add these six audio files:
   intro-theme.mp3
   profile-selection.mp3
   near-miss.mp3
   pillar-crossed.mp3
   victory.mp3
   game-over.mp3
5. Open index.html in a modern browser.

The game opens directly on profile selection. Choose Custom Profile to use a photo
from your device, or Game Profile to use the default character. Your custom photo
is processed locally in the browser and is not uploaded to a server.

Gameplay: tap anywhere in the game area (except Pause), click, or press SPACE,
Arrow Up, or W. Cross 10 pillars to win. The fifth pillar is gold; the background
changes as you progress. The playfield uses nearly the full screen.

Difficulty: Easy, Medium, Hard. Pause, resume and sound controls are included.
Replace the six audio URLs at the top of script.js if you use different filenames.
